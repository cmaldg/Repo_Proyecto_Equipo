# La Influencia de Festivales Internacionales 

## Descripción
Este sitio web presenta una pieza narrativa individual que analiza la relación y correlación entre el triunfo de intérpretes en festivales de cine europeos (Cannes, Venecia, Berlín) y su efectividad como filtro previo o trampolín hacia las nominaciones de los Premios Óscar. 

A través del caso de estudio de Jessie Buckley y su "triple corona" (Globo de Oro, BAFTA y Óscar), la página integra texto narrativo, imágenes de apoyo y visualizaciones de datos cuantitativos que examinan cómo las barreras idiomáticas, el mercado de origen y los requisitos de asimilación condicionan el éxito de actores extranjeros en la Academia.

## Proceso
1. **Organización de contenido:** Primero estructuré la crónica periodística a partir de los hallazgos de la Entrega 03, adaptando la narrativa para abrir directamente con el hito de Jessie Buckley y articular la discusión sobre la hegemonía anglófono-estadounidense.
2. **Estructura HTML:** Construí la pieza narrativa utilizando HTML semántico estructurado mediante etiquetas principales (`head`, `body`, `h1`, `h2`, `p`, `img`, `ul`, `li`, `blockquote` y `hr`).
3. **Integración de visualizaciones:** Incorporé los gráficos estadísticos desarrollados a partir de la base de datos propia (1933–2026), ajustando sus propiedades visuales mediante estilos CSS en el encabezado para asegurar una escala proporcional y lectura adaptativa (responsiva) en distintas pantallas.
