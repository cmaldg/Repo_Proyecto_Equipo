# La Globalización de los Oscar

Bienvenidos y bienvenidas al repositorio oficial del proyecto de investigación periodística **"La internacionalización de los Oscar"**. Este espacio reúne nuestras bases de datos, metodologías y webstory. 

El objetivo central de este trabajo es medir cuantitativamente la representación internacional en las categorías principales de actuación ("Mejor Actor" y "Mejor Actriz") de los Premios Oscar a lo largo de todas sus ediciones.
